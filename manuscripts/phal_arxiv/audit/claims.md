## Figure inputs

All figures are generated by `scripts/make_figures.py` from `data/plot_data.json`.

| Figure | JSON keys | Rendering decisions |
|---|---|---|
| 01 | Diagram only; implementation responsibilities | Schematic, no measured scaling or performance implied. |
| 02 | `geometries` | Stored extxyz coordinates converted to JSON; known alkane connectivity. Separate PCA projection per structure, common scale. Orange outlines are imposed sites, not detected errors. |
| 03 | `calibration`, `c16`, `c32`, `targets` | All six settings retained, including failure. No invented error bars. |
| 04 | `boundary`, `c16`, `c32_costs` | Core atoms only; two elements shown separately. Costs on logarithmic axis; parent and per-fragment comparison denominators stated. |
| 05 | `arms`, `accuracy_targets` | Two seeds visible; actual model evaluations only. Lines are guides, not intermediate trained models. Shared initial-label costs omitted consistently. |
| 06 | `closed_loop` | Actual global event steps × 0.5 fs; validation error vs actual cumulative label counts; every seed topology fraction shown. |

## Implementation sources inspected

Paths below are relative to the original GMD_active repository unless prefixed by `../GMD_SGT`.

- `src/gmd_active_learning/monitors/{staged_monitor,scoring,lj_local,lj_projection,ensemble_deviation}.py`: scheduling, heuristic scores, LJ sign and fit, committee vector dispersion.
- `src/gmd_active_learning/events/`: event context, identities and completeness.
- `src/gmd_active_learning/datasets/`: force masks, energy weights and exported datasets.
- `tools/experiments/alkane_hotspots/{fidelity,training,closed_loop}.py`: fragment audit, acquisition experiment, topology and online evaluation.
- `../GMD_SGT/gmd_sgt/training/loss.py`: batch-normalized weighted force RMSE; no gradient from zero-weight force targets.
- `../GMD_SGT/gmd_sgt/training/trainer.py`: scheduler updates per optimizer step, rather than per epoch.
- `docs/demos/alkane_hotspots.md`: completed-study documentation and exploration history.

The manuscript is a source- and artifact-backed draft. These audits do not certify the underlying scientific model or replace review of complete raw output archives.
